# TikTok Downloader Bot

Telegram-бот, который скачивает видео из TikTok без водяного знака: по ссылке в личке или в любом чате через inline-режим `@имябота <ссылка>`.

Написан на Python: [aiogram 3](https://github.com/aiogram/aiogram) + [yt-dlp](https://github.com/yt-dlp/yt-dlp), с запасным способом скачивания через API [tikwm.com](https://www.tikwm.com).

## Возможности

- 📩 **Личка** — отправь боту ссылку, он ответит видео.
- 💬 **Inline-режим** — в любом чате напиши `@имябота https://vm.tiktok.com/...` и выбери результат: видео отправится прямо в переписку.
- ⚡ **Кэш** — `file_id` хранятся в SQLite, повторные запросы одного видео отдаются мгновенно, без скачивания.
- 🔁 **Два способа скачивания** — сначала yt-dlp, если он не справился — tikwm.
- 🌍 **Прокси** — http или socks5, для обоих способов.
- 🧾 **Понятные ошибки** — бот пишет реальную причину, если видео не скачалось.
- 🐳 **Docker** — запуск одной командой, yt-dlp обновляется при каждом старте.

## Как работает inline-режим

Бот не может загрузить файл напрямую в чужой чат, поэтому:

1. Если видео уже есть в кэше — сразу отдаётся готовое видео.
2. Если нет — в чат уходит сообщение «⏳ Загружаю видео…».
3. Бот скачивает видео, загружает его в служебный чат, получает `file_id` и заменяет заглушку на видео.

## Установка

### 1. Настрой бота в [@BotFather](https://t.me/BotFather)

- `/newbot` — создать бота и получить токен;
- `/setinline` — включить inline-режим;
- `/setinlinefeedback` → **Enabled** — обязательно, иначе заглушка не заменится на видео.

### 2. Создай служебный чат

Создай приватный канал, добавь бота администратором и узнай ID канала (вида `-100…`, например через [@getidsbot](https://t.me/getidsbot)). Туда бот будет складывать видео ради `file_id`.

### 3. Заполни `.env`

```bash
cp .env.example .env
```

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен от @BotFather |
| `CACHE_CHAT_ID` | да | ID служебного канала |
| `PROXY` | нет | `http://…` или `socks5://user:pass@host:port` |
| `COOKIES_FILE` | нет | cookies.txt (формат Netscape) для yt-dlp |
| `DB_PATH` | нет | Путь к базе кэша, по умолчанию `cache.sqlite3` |
| `MAX_PARALLEL` | нет | Сколько видео качать одновременно, по умолчанию 3 |

### 4. Запусти

```bash
pip install -U -r requirements.txt
python bot.py
```

Или через Docker:

```bash
docker build -t tiktok-bot .
docker run -d --env-file .env \
  -v $(pwd)/data:/app/data -e DB_PATH=/app/data/cache.sqlite3 \
  --restart unless-stopped tiktok-bot
```

## Ограничения

- **Россия:** TikTok не отдаёт российским IP видео зарубежных авторов. Запускай бота на зарубежном VPS или укажи зарубежный `PROXY`.
- Bot API не даёт ботам загружать файлы больше 50 МБ.
- Фото-карусели (слайдшоу) пока не поддерживаются.
- TikTok регулярно меняет сайт — держи yt-dlp свежим: `pip install -U "yt-dlp[default,curl-cffi]"`.
- tikwm.com — сторонний бесплатный сервис с лимитом около 1 запроса в секунду.
